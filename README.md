# Neural Calibration

A gamified, cyberpunk-aesthetic AI literacy assessment. Not trivia. Not acronyms. A practical test of how you think with AI — communication, orchestration, capability awareness, iteration, and safety.

## What Makes This Different

| Traditional Quiz | Neural Calibration |
|------------------|-------------------|
| "What does LLM stand for?" | "Design an agent pipeline for this real task" |
| Multiple choice memorization | Interactive scenario simulation |
| Static score | XP, levels, badges, radar profile |
| Generic certificate | Personalized cognitive alignment map |

## The Five Missions

1. **The Brief** (Signal Clarity) — Turn vague requests into answerable prompts
2. **The Factory** (Swarm Logic) — Build multi-agent workflows for complex goals
3. **The Mirror** (Reality Check) — Judge what AI can and cannot do reliably
4. **The Loop** (Feedback Loop) — Iterate and refine prompts through rounds
5. **The Warning** (Risk Protocol) — Spot hidden dangers and choose safeguards

## Design DNA

- **Cyberpunk minimalism**: Dark void backgrounds, neon accents (cyan, magenta, amber), grid overlays, scanlines
- **Gamification without templates**: XP as "Neural XP", levels as "Cognitive Tiers", badges as "Protocols Unlocked"
- **Modular & responsive**: Works on phone, tablet, desktop — vertical or horizontal
- **Progressive disclosure**: Complexity reveals itself as you advance

## Tech Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Framer Motion
- Recharts
- Lucide React
